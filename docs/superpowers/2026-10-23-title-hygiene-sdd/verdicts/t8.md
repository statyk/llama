## What was implemented
`apply_lossless(kept, tag_titles, tag_source, *, in_scope, files, ordering, recovery_basis, desc, canonical, metadata_norms) -> LosslessResult` has the exact signature and fields from the brief. It is pure.
- **Scope:** when `in_scope` is False it returns `declined="out of scope"` and changes nothing.
- **Format:** it uses the first format in `LOSSLESS_TITLE_FORMATS` that is not `ordering["format"]` and whose `sibling_format_titles(recovery_basis, filter_files(files, fmt)[0])` exists with `title_fraction > 0`. This is the same call shape as `_recover_format_titles`. When no format qualifies it returns `declined="no lossless format"`.
- **Re-admitted files:** each kept file looks up `mapped.get(name)`. A re-admitted file is in `kept` but not in the basis, so it has no lossless title. It is never changed and never votes.
- **References:**
  - (a) is `desc.cleaned[i].text`, only when `len(desc.cleaned) == len(kept)`.
  - (b) is `canonical.items[i].title`, only when `len(items) == len(kept)`.
  - The single reference used by C2 and the skip is (a) when there is a list, else (b).
- **Show-level skip:** if 2 or more lossless tags `agrees` with the reference at i±1 but not at i, it returns `declined="off by one"` with a note and changes nothing.
- **Lossless "eligible":** the lossless tag is real (`is_real_title` and not `is_placeholder_text`), passes `hygienic_title(lt, metadata_norms)` (default `require_real`), and is not `_vetoed`.
  - `_vetoed` catches three shapes: the whole tag in `[...]`; a tag ending in `:`; the delivered title plus only trailing `@ ^ * #`.
- **C1 target:** the lossless tag is eligible, and the delivered tag is neither real nor the 2a shape. That means blank, a placeholder (`tmp`), or failing `is_real_title`.
  - The 2a shape: the `tag_core` has an alphanumeric character, the core is not `is_junk_tag`, and the tag is not `is_placeholder_text`.
- **C2 candidate:** the lossless tag is eligible, and the delivered tag is real or (non-blank, failing `is_real_title`, 2a shape).
- **C1 adoption (the plan's reading):**
  - Each target records `c1_verdicts[i] = (agrees with (a) | None, agrees with (b) | None)`.
  - (c) is computed only when some target agrees with neither (otherwise `c_holds=None`). It holds when at least `siblings.MIN_ANCHORS` comparison stems agree and none disagrees. A comparison stem is one where both tags are real.
  - If any target fails all three, C1 fills nothing on the show. The result then has `declined="C1 unconfirmed"` and the note `lossless titles declined: C1 unconfirmed (track <n> '<lossless>')`, naming the first such target.
- **C2:** it needs a reference, `fuzzy_norm_title` must differ, the lossless tag must agree with the reference, and the delivered tag must not.
- **Output:** every change writes `lossless title: track <n> '<old>' -> '<new>' (<C1|C2>)` and sets the source to `sibling-format`. Every other track keeps `tag_source`.

## Judgement calls (the brief left these open)
1. **Notes for quiet declines.** "out of scope" and "no lossless format" set `declined` but write **no note**. Most shows hit one of the two, so a note would be noise on nearly every show. Notes are written only for "off by one" and "C1 unconfirmed". Pinned by the `r.notes == ()` assertions.
2. **`declined` beside C2.** `declined` can be "C1 unconfirmed" while C2 changes are still made on the same show. C2 is independent of C1's show-level refusal.
3. **`hygienic_title` on C2 too.** I applied it to the lossless tag for C2 as well as C1. The brief lists it only for C1, so this is a stricter reading on the tag-replacing surface. It guards the over-length lossless tag that `loosely_same_title`'s containment would otherwise let agree. Pinned for C1 only (`test_c1_lossless_must_be_hygienic`), and the operator may want to rule on it.
4. **Which lossless tags the off-by-one skip counts.** It counts every non-blank lossless tag at a kept position, vetoed or not and target or not. The spec says "two or more lossless tags".
5. **Comparison stems for (c)** use the raw lossless tag with no veto filter. Both tags must be real tags, so a 2a-shaped or non-real delivered tag is never a comparison stem.
6. **The 2a shape's "alphanumeric"** is read as `any(ch.isalnum())` on the core, the way `accept_short_tags` tests it.
7. **(b) does not check canonical confidence.** Only the count is checked, as the spec says. The whole-tape `setlist` rung, by contrast, also requires confidence != low.
8. **The trailing-symbol veto** compares exact stripped text (case-sensitive) after removing a trailing run of `@ ^ * #`.

## Concerns
- **The derektrucksband test differs from the real show.** In the real show the setlist.fm canonical (`Sailing On`, …, with conflicts `Down in the Bottom` and `44 Blues`) is SHIFTED against the tape. With that canonical as the only reference, the off-by-one skip would decline C. The real show is rescued because its own description is a count-matched admissible list (14 entries for 14 files; `read_numbered` gives 2 blocks, boundary `disc`), and track 1 then fills via (a).
  - The brief's test (canonical only, C1 via (c)) uses a canonical shifted at item 1 only, so the skip does not fire there.
  - A second test, `..._with_the_taper_list`, uses the real description head and shows the (a) route.
  - The yield gate should confirm the real show takes that route once Task 11 wires C in.
- **Belt-and-braces clauses.** The trailing-symbol veto (greensky) is redundant inside `apply_lossless`: `Blue Night @` and `Blue Night` are `fuzzy_norm`-equal, so C2 never fires. It is pinned only through `test_veto_predicate`. The C2 "fuzzy_norm differs" clause also looks equivalent (see the mutation check). Both are kept because the spec names them.
- **Wiring (Task 11's job).** Overrides must still win: C runs at the tag layer, so an `overrides.titles` position may get a C note before the override replaces it. If notes for overridden positions are unwanted, the caller should drop them, as it does for 2b notes.
