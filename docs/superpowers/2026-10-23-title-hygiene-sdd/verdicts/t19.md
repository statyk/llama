## Judgement calls (the brief left open)
1. "held now / would-hold on a fresh get / currently packaged": a cleared hold (base holding = still-held, still-held-package, newly-held, or needs-llm on a held show; cand replayable and not holding) is "held now" when state is held; else "would-hold on a fresh get" when the row's `stripped` is non-empty (an overrides-stripped arm replaying a shipped show: the overrides were masking the hold); else "currently packaged". In an as-is arm the middle bucket is therefore always empty. Pinned by test_holds_delta_three_way_split.
2. "voiced" = state delivered AND station manifest `dj_audio` non-null via the existing `_is_voiced` (delivery_path from config); voiced is its own state label in holds_delta and title_changes.
3. title_changes.txt covers cand states packaged/delivered with outcome clean or clean-changed ("stays unheld"); compares base vs cand titles (not vs stored). Base titles = row `titles` if present, else stored show.json + base `title_changes`. Positions with no recorded path print `(unattributed)`.
4. needs-LLM rows have `cascade == {}`, so "D shows reaching the LLM branch" is read from `desc_position > 0` or any note containing `desc-position` on a needs-llm row; agreement decline from `cascade.d_failed == "agreement"` or a `positional fill declined: desc-position agreement` note. A D agreement decline on a needs-llm row with no such note is invisible.
5. Stratum 1 = newly cleared AND wholly untagged (dump `arms.all.record.wholly_untagged`) AND (d_fills >= 3 OR self_filled): "all self-filled included" read as self-filled regardless of D count. The sample draws from newly cleared minus stratum 1, round-robin over the path signature (sorted distinct path tokens without `+5`), seeded shuffle, so rare paths are over-represented relative to proportional. delivered_changes lists shows with a changed title TEXT on delivered/voiced (source-only changes excluded). "Newly cleared" = compare's `_newly_cleared` (CLEARING outcomes).
6. New file `title_rows.json` is not in the brief; `packets --cmp DIR` needs per-show state/titles/paths, which compare's text files lack. Rows only for shows that were newly cleared, changed a title, or have a slice-4 path; extras outside that fall back to the dump's `all` arm.
7. parity exit code 1 on mismatch (brief silent).
