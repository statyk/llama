## Implemented (packages/llama/src/llama/title_hygiene.py, appended section "Slice 1")
- `SetlistPlan(mode, fills, deferred, declined, notes)`, frozen, fields exactly as the brief.
- `plan_setlist_rung(...)`, the brief's signature. Mode order, first match wins:
  none (len(items) != len(filenames) or confidence low) -> today (slice1 off: every
  s_position whose item is not `is_placeholder_text`, nothing declined, no notes) -> chosen
  (source "chosen" and desc_used and slice2: nothing) -> untagged (no fills, declined = all
  s_positions, Q1 note or the chosen-canonical note) -> deferred (desc_used and slice2:
  deferred = every s_position's item text, declined = those positions) -> gated (checks 1
  and 2; show-level failure fills nothing, declines all s_positions, one note naming the
  first failure; per-track failure declines that one, one note each).
- `apply_deferred_setlist(tracks, plan, d, *, tag_titles, metadata_norms)`: no-op outside
  `deferred` mode; on `d.shift` fills nothing; otherwise judges the deferred positions still
  `unresolved` and not D `filler entry` declines, re-running checks 1 and 2 against the
  current tracks; fills ship today's item text with source `setlist`.
- Private helpers `_s_check` (checks 1+2, shared by gated and deferred) and `_s_notes`
  (the fixed note strings, rung `setlist`). Constants `SETLIST`, `_Q1_NOTE`,
  `_Q1_CHOSEN_NOTE`. New imports: `clean_entries`, `is_placeholder_text`.
- No edits to titles.py/structure.py/setlist.py/gather.py. `git diff main -- setlist.py`
  is empty (structure.py's diff vs main is Task 4's, untouched here).

## Judgement calls (each pinned by a test)
1. Q1/chosen note only when s_positions is non-empty (`test_untagged_with_no_s_positions_
   writes_no_note`): with no S candidate nothing is withdrawn. Mode stays `untagged`, so the
   gate's R5 Q1 count should count `untagged` plans with a non-empty `declined`/`notes`, not
   mode alone, or it will count shows where S had nothing to fill.
2. S candidate cleaning: `clean_entries` over the S candidates (s_positions' items, in
   position order), so the leading-track-number vote is taken over that list, identically in
   gated mode and in `apply_deferred_setlist` (deferred == every s_position's item). Not over
   the whole canonical, which apply does not have.
3. Today's `is_placeholder_text` refusal kept in gated and deferred modes (spec: "stays; this
   check is a superset"), applied AFTER check 1: silent, per track, not declined (exactly
   today's handling), and the refused candidate is not a check-2 candidate. A check-1 failure
   on the same entry still counts first. Test: gated_ships_todays_item_text_and_keeps_...
4. Check 2's candidates are the entries that did not fail check 1 per track (show-level
   failures stay in, as in `decide_d`); notes carry the cleaned text, as `d_notes` does.
5. On a D shift, apply writes ONE S note naming D's first SHIFT check and its detail:
   `positional fill declined: setlist tape agreement (track 1 'Sugaree')` (the show-level
   fixed format). The brief does not say whether S notes this; the alternative is silence
   with D's note alone (which may name a hygiene check first and hide why S did not fill).
6. A D that passed (no show failure) still lets deferred S fill its per-track check-1
   declines (`slot placeholder`, `metadata`) but never `filler entry`. `d=None` (D had no
   unresolved track) proceeds with the checks, which find nothing open.
7. Gated check-2 neighbours are synthetic Tracks: tag text with source `tags` where
   tag_real, else unresolved (so a 2b-demoted real-looking tag is no neighbour).
