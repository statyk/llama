## What it does
`./.venv/bin/python scripts/title_hygiene_probe.py dump [--config P] [--slugs F] [--jobs N] --out DIR` writes `DIR/dump.jsonl`. Its first line is `{"_meta": {sha, config_fingerprint, setlistfm_configured, n, align_coverage_threshold}}`, then one row per show (keys sorted). It refuses (exit 2) an `--out` that overlaps the library root and a `llama` imported from outside this tree, reusing `replay_holds._check_identity`, `_overlaps` and `Refusal`.

Each show is replayed on two views:
- **Fresh-get view:** `replay_holds._shadow(d, …, ("titles", "set_breaks", "encore_after"))`. It writes only in a temp scratch dir; the live overrides file stays byte-identical (tested). Arms: `none`, `all`, and `all-slice1` … `all-slice5`.
- **As-is view:** the show dir itself. Arm `none` only.

How each view runs:
- **Capture of today's title block.** `gather.accept_short_tags` and `gather._sibling_transfer` are wrapped as module patches, armed only while `compute_legs` runs, so the cascade's own `accept_short_tags` call is never captured. The wrapper records the tracks just after 2a, the `op_notes` prefix read from the caller's frame plus 2a's notes, and sibling-align's notes. With `--jobs N`, each Pool worker installs its own wrappers in its initializer. With `--jobs 1` they are installed in-process and removed afterwards.
- **Building the inputs.** `title_inputs` builds them from `ia.metadata(stored.identifier)`, `read_overrides(view)`, `prov.candidate` and `jerrybase.lookup(artist, date)` (only when `[jerrybase] enabled`). `build` calls `build_canonical(…, setlistfm=setlistfm_client(cfg), provider=None)`, so canonical building is cache-only and makes no LLM call. No field is reconstructed from the captures.
- **Arms.** `title_cascade(inp, enabled=ARMS[name])` runs for each arm. Every arm containing `slice5` gets `cosmetic_strip` last, and a changed position's path gets a `+5` suffix.

Per arm the row carries:
- tracks (title, source);
- `paths`, `self_filled`, `op_notes` (plus slice-5 notes), `struct_notes`;
- `record` (the `CascadeRecord` as JSON; `DDecision` also gets `shift`);
- `coverage` = `align(tracks, canonical, aliases=family_aliases).coverage`.

`gate0` / `gate0_as_is` mean arm `none` equals today on that view in per-track titles and sources, then operator notes, then sibling notes. `gate0_diff` / `gate0_as_is_diff` name the first difference (`track N title: …`, `op_notes[i]: …`, and so on). A `title_inputs` or cascade exception counts as gate0 false, with its message.

Other row fields:
- slug, state, voiced, identifier, artist, family, description, `metadata_norms`;
- `today` (n, title, source, duration, filename, raw_tag) with `today_op_notes` and `today_struct_notes`;
- `today_as_is` (title, source);
- `today_flags`, `today_needs_llm`, `today_outcome` ([outcome, would_be]), `today_notes` (gather + vet), all from the fresh-view legs;
- `stripped`, `structure_override`, `title_override`;
- `desc`: used reader, and for `numbered`/`parse` either the reason or the list (n, boundaries, entries with raw text, block and every `Cleaned` field);
- `canonical` (source, confidence, needs_llm, items with title/set/segue);
- `arms`, `arms_as_is`, `unreplayable`/`unreplayable_as_is` (compute_legs errors), `slfm_miss`.

Alternatives, all on the fresh-get `all` arm. Positions are 0-based in `alt_*` and `record`.
- `alt_bare_number` (R14): bare-number S candidates, with `judge` and `exemption_decided` (judge with the own tag core differs from judge with `own_core=""`).
- `s_candidates` (extra, for R14 and R19's S half): every S candidate, cleaned as `_s_check` cleans them (the leader vote is taken over all of them). Each carries every `Cleaned` field (incl. `trailing_time_stripped`) and both judge results.
- `alt_hygiene_all_entries` (R15): show-level check-1 failures over every entry of the count-matched list. Each is marked `candidate` when it sits at a pre-D open position (positions unresolved after the cascade, plus D fills, plus deferred-S fills). `extra` lists the non-candidate ones.
- `alt_encore_restart` (R16): `read_numbered` with and without `encore_header=True`, `admits_new`, and `count_matched`.
- `alt_c1` (R17): `declined`, `c_holds`, the per-target (a)/(b) verdicts and adoption, `would_pass_alone`, and `via_c_where_ab_disagreed`.
- `alt_bracketed_s` (R4): `{"applies": false}` on a chosen canonical. Otherwise the S/S-deferred fills, those that `remain` / are `dropped`, and per run `left`/`right`/`closed`.
- `alt_encore_fold` (R10): `block_size_mismatch` with and without the fold, plus `differs` and `wholly_untagged`.
- `alt_check2_cleaned` (Task 5 ruling): every `adjacent_duplicate` call in the `all` arm is captured with its rung (D / S / S-deferred, read from the caller frame) and re-run as `adjacent_duplicate_cleaned` (`clean_one` on neighbour titles). `would_decline[rung]` lists the fills that call made when only the cleaned version hits.
- `alt_c2_containment` (Task 8 ruling): each C2 replacement with its reference (list or canonical), `strict` (core equality or `fuzzy_title_eq`), `containment`, `ratio` and `agrees`. `containment_only` lists the ones that are not `strict`.
- `alt_filler_confirm`: slice-4 confirmations whose list entry was `Filler:`-marked. The record names the entry index, so this was derivable anyway; it is added for convenience.

## Judgement calls (the brief left these open)
1. `_meta` carries one extra key, `align_coverage_threshold`, which Task 14's held approximation needs. The four required keys are present unchanged.
2. Gate 0 compares exactly what the brief names (per-track titles and sources, op notes, struct notes), not whole `Track` dumps. Track count is checked first.
3. Gate 0 is computed whenever today's block was captured, even if `compute_legs` failed later (in vet). `unreplayable` records the `compute_legs` error. A per-show probe exception is caught by `_safe_one` and recorded, so it never stops the run.
4. `alt_bracketed_s` applies `structure.gap_span` verbatim. Its anchors are positions with an `INDEPENDENT_SOURCES`, non-filler title, after the S fills are set back to unresolved. That keeps gap_span's leading-edge branch (lo == 0 with a right anchor). Per-run `left`/`right` are recorded so Task 14 can apply a strict both-sides reading instead. Pinned by `test_bracketed_s_keeps_only_runs_closed_by_independent_song_titles`.
5. `alt_c2_containment.containment_only` follows the brief's parenthetical: C2 rows that are not `strict` (core equality or `fuzzy_title_eq`). Each row also carries `containment` and `ratio`, so Task 14 can tell the containment arm from the ratio arm. Pinned by `test_c2_containment_flags_agreement_only_through_containment`.
6. `alt_check2_cleaned` identifies the rung from the caller's frame. A fill counts as "would decline" only when the built check passed and the cleaned one hit; the fills are those that call's rung actually made. Pinned by `test_check2_cleaned_compares_a_cleaned_neighbour`.
7. R15's candidate set is reconstructed as positions still unresolved after the cascade, plus D fills, plus deferred-S fills. This equals the unresolved set D saw, because only D and deferred S act after D's input and both fill only unresolved positions.
8. `coverage` is `align()` over the arm's final tracks (after slice 5) on every arm and view, including override and empty-canonical shows, where gather itself would force 1.0 or skip. Task 14 uses `structure_override` to tell those rows apart.
9. The `today` rows' `raw_tag` comes from `title_inputs`' `kept`, keyed by filename. Gate 0 proves that `kept` equals gather's on every row.
