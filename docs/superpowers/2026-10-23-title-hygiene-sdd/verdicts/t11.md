   (`_without_override_positions`): the change is undone (title and source back to the
   delivered layer), not counted in `changed`, its note dropped. A C1 show-level
   `C1 unconfirmed` decline CAUSED by a target at an override position is not filtered
   (conservative: it only declines more). Pinned in
   test_overrides_survive_every_new_rung_and_anchor_check_3.
2. `wholly_untagged` and `resolve_titles`' layer demotions use 2b over the delivered
   layer minus C-changed INCLUDING override positions (as today's resolve_titles demotes
   them); the 2b notes, 2a/slice 4 `demoted`, and `fetch_siblings` use the set minus
   overrides (today's). A `tmp` at an override position therefore does not count as a
   real tag toward wholly-untagged.

   the plan only fills on a count-matched, not-low canonical, so it is the same gate.

   (Task 16 joins them).

   D, deferred S.
