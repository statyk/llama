## What was implemented (packages/llama/src/llama/title_hygiene.py)
- `SHIFT_CHECKS` = {adjacent duplicate, tape agreement, written durations, block size, sibling durations, agreement}.
- `_DISC_INDEX` / `_SET_INDEX` verbatim from Global Constraints, applied to the stem (basename minus extension), last match wins.
- `block_size_mismatch(filenames, dl, *, fold_encore=True) -> str | None`: folds `encore` blocks into the preceding block, then is inert unless 2+ blocks, every filename yields the index, the index takes exactly as many values as blocks, and each index value is one contiguous run in play order. Set index replaces disc index when every remaining boundary is `set` and every filename yields one; otherwise the disc index (every file must yield it). Returns the note detail `track <n> '<text>'` of the first entry of the first mismatched block.
- `sibling_disagreement(cands, donor)`: pairs = rows with a length-1 `donor_span` shared by no other row, `row.track - 1` in `cands`, donor title (`DonorTape.titles[j0]`) non-empty and `is_real_title`, neither side filler. Fewer than `MIN_ANCHORS` pairs -> inert. First pair where `agrees` (check 3's comparator, no aliases) is False -> (pos, candidate, donor title).
- `DDecision(fills, failed, track_declines)` frozen, `.shift` property.
- `decide_d(...)`: None on count mismatch or no `unresolved` track. Candidates = cleaned entries at unresolved positions, judged with `track_no=i+1`, `first=(i==0)`, `stem` = file stem, `own_core=tag_core(tag_titles[i])`. Per-track declines go to `track_declines` and are not candidates thereafter; every show-level check-1 failure is recorded (one per failing candidate, position order). Then check 2 (over the remaining candidates and current neighbours), check 3, written durations, then (only when `wholly_untagged`) block size and sibling durations (`donor()` called only then and only when candidates remain), then agreement. Fills = all remaining candidates (cleaned text) iff `failed` is empty.
- `apply_d`: stamps `desc-position` on still-`unresolved` positions only (never overrides).
- `d_notes`: one show-level note from `failed[0]` (`positional fill declined: desc-position <check> (track <n> '<text>')`) plus one per `track_declines` entry (`positional fill declined: desc-position track <n> <check> '<text>'`).
- `is_self_filled`: `d` not None, `not d.failed`, at least one song-like track, every song-like track `desc-position`.
- Refactor: `agreement_share` now delegates to a private `_agreement` that also returns the first unmatched song-like entry (used for the agreement note detail). `agreement_share`'s behaviour is unchanged (Task 5 tests green); `aliases` still reaches only the agreement computation.

## Judgement calls (the brief left open)
1. Failed-detail format: every `failed` detail is exactly `track <n> '<text>'` so `d_notes` writes the fixed string with no reformatting. `<text>` is the cleaned entry text (check 1 / 2: the candidate; check 3 and written durations: the list entry at that position; sibling: the candidate). For written durations the cleaned text no longer shows the duration.
2. Block-size detail: first entry of the first mismatched block. Agreement detail: first song-like entry no canonical item matches (needs aliases, hence the `_agreement` refactor rather than a second alias-aware matcher).
3. Check 1 records one `failed` row per failing candidate (all of them, position order), so `failed` may hold the same check name several times (bfft: both `"Set" N:` lines).
4. Check 2 and the sibling check see only candidates that survived the per-track declines (a `?` or `Filler:` entry is not a fill, so it is not a neighbour candidate). Show-level-failed candidates stay in.
5. Sibling pairs: a filler-neutral pair does NOT count toward `MIN_ANCHORS` (only comparable pairs count). The more aggressive reading (neutral pairs count) would make the check fire with a single disagreeing pair; I followed siblings.py's own principle that one pair is not evidence. Rows of any verdict count (the donor title is read from `DonorTape.titles`, not `row.proposed`).
6. `donor()` is not called when every unresolved position was per-track declined (no fillable candidate). Consequence: on such a show D records no sibling failure; S deferred (Task 7) could then fill slot-placeholder positions without a sibling shift check. Edge case; flagged for Task 7's reviewer.
7. `is_self_filled` requires at least one song-like track (a tape of only filler is not self-filled).
8. `block_size_mismatch` groups are compared in play order (k-th block vs k-th contiguous index run), not by index value.
