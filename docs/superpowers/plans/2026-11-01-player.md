# Playout phase 4 player: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder player with a designed cassette-and-ticket page that shows what's on, recovers from dropouts, feeds the car display and works as a home-screen app.

**Architecture:** Static files only. New JS, CSS, fonts and pictures live under `antenna/public/assets/`, split into pure tested modules and thin DOM wiring. `public/index.html` and `public/offair.html` are rewritten and bundled by `npm run pages`, with the clock unchanged. `site.py` gains a briefing parser and publishes a `sections` field that the static show page and the slide-up panel both render.

**Tech Stack:** Plain HTML, CSS and ES modules, hls.js, Vitest in the Workers pool, Playwright for the smoke test, Python 3.11 and pytest for `site.py`.

**Spec:** `docs/superpowers/specs/2026-11-01-player-design.md`. Mockups: `docs/superpowers/2026-11-01-player-mockups/` (`cassette-tickets.html` right-hand "Concert ticket", `desktop-layout.html` layout B, `show-page.html`).

## Global Constraints

- Nothing billed per listener: every new listener request is a static object from the edge cache. No Worker route. No third-party request.
- All untrusted text reaches the page as text: escaped on the server, `textContent` in the browser, never `innerHTML`.
- A link is emitted only for a URL starting with the literal `https://archive.org/`; otherwise the button is left out.
- Every ticket, notes and share URL is built from the encoded slug. The file's `notes` and `page` fields are never read.
- `antenna/public/player.js`, `nowplaying.js` and `style.css` stay byte-for-byte unchanged and stay published.
- `antenna/src/` changes only through `npm run pages` regenerating `src/pages.ts`.
- `/assets/` returns 403 while blocked, so `offair.html` uses inline styles, system fonts and no scripts. The kill-switch rule does not change.
- Concert dates are formatted from the string, never through `Date`. Blank fields are left out, never printed as "null".
- Palette: cream paper, tape brown, oxblood, muted teal. No rainbow, no Internet Archive branding.
- Exact copy: "Live concert tapes from the Live Music Archive, around the clock."; "Show notes are AI generated and may contain mistakes."; "Hear the full tape on archive.org"; "LMA RADIO PRESENTS"; "GEN ADM"; "Open the show page"; "No notes yet."; "Reconnecting…"; "Lost the stream."; "The station is off the air."; "Playback was blocked."; "This browser can't play the stream; open the stream URL in VLC."; keys "Play" and "Stop".
- `site.py` runs on Python 3.11 and transmitter never imports llama or emcee.

## Review Focus

1. A page left open until the published timeline runs out: "Coming up" says so rather than rendering blank, and the page recovers at the next fetch. Pinned in Task 3.
2. Air times across midnight, in a non-Eastern zone, on the day the clocks change: day label and zone name follow the listener. Pinned in Task 3.
3. A very long band name (`...And You Will Know Us By the Trail of Dead`) on a 320 px phone: no sideways scroll on the label, tickets or panel. Pinned in Task 10.
4. A show with null fields or no files yet: no "null", and Now playing falls back to the band. Pinned in Task 3.
5. Fast repeat taps: Stop during a retry delay never restarts audio, and tapping a second ticket before the first's notes arrive shows only the second. Pinned in Tasks 4 and 9.
