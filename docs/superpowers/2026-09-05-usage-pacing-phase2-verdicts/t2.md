The `_WEEK_MODEL_RE` widen mutation turned out to already be caught by F2's new test (see

`re.M`'s multiline `$`. I mutated it and reran the full 11-test suite against the mutant on the
private copy — 11/11 still passed, confirming it changes nothing observable, not that a test is
missing. No test can discriminate two programs that compute the same function; noted rather
than chased.
