### The survivor, and why I did not chase it

`m15` passes `None` where `_checkpoint_pause` passes `failures or []`. I proved the
equivalence mechanically rather than by reading: writing a marker both ways under the copy
produces byte-identical JSON (`updated_at` excluded), because `sessions._write` already
does `failures or []`. Output of the proof:

```
failures=[]   -> {"failures": [], "outcome": null, "pause_reason": "limit", ...}
failures=None -> {"failures": [], "outcome": null, "pause_reason": "limit", ...}
```

No observable state distinguishes them, so no test can. I kept `failures or []` anyway —
it matches the brief and the per-show loop's own call site.
