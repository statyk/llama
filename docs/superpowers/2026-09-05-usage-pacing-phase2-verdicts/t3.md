### What was added

Following `packages/herder/tests/test_claude_cli.py`'s `patch_run`/`FakeProc`
pattern (`monkeypatch.setattr(subprocess, "run", fake_run)` on the shared
`subprocess` module — no process spawned, auto-reverted), added five tests to
`packages/herder/tests/test_usage.py`:

- `test_cli_runner_passes_usage_argv_and_isolation_args` — pins `cmd[0:3] ==
  ["claude", "-p", "/usage"]`, `--output-format json`, and that
  `claude_cli.ISOLATION_ARGS` is the argv's tail.
- `test_cli_runner_uses_neutral_cwd_and_subprocess_env` — monkeypatches
  `claude_cli._neutral_cwd`/`_subprocess_env` to sentinel values and asserts
  they land in `subprocess.run`'s `cwd=`/`env=` kwargs, plus
  `capture_output=True`, `text=True`, `timeout=60`.
- `test_cli_runner_returns_none_on_nonzero_exit` — a `returncode=1` fake
  proc must yield `None`, not its stdout.
- `test_cli_runner_survives_a_missing_binary` — `FileNotFoundError` (an
  `OSError` subclass) from `subprocess.run` yields `None`.
- `test_cli_runner_survives_a_timeout` — `subprocess.TimeoutExpired` (a
  `SubprocessError` subclass) from `subprocess.run` yields `None`.

Added `import subprocess` and `from herder import claude_cli, usage` to the
test file's imports (was `from herder import usage`).
