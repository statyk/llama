- [ ] **Step 9 — is the donor-span slide real, or a synthesis artifact? Carried from Task 4** (SYNTH vs REAL — this one turns on the distinction). C+ exists primarily to catch a *localised donor-span slide with high anchor agreement*: the alignment slides, the ratio stays blind, and wrong titles ship. **The sweep observed that case exactly once, at agreement exactly 0.80, in the synthesised prefix-mask population.** Task 4's regression fixture turned out to reproduce a *tag* shift rather than a donor-span shift (genuine machinery, wrong mechanism), which sharpens the question rather than answering it. **THE DECISIVE QUESTION — C+'s PRECISION on the corpus.** Put Task 4's two regression fixtures side by side and the pattern is uncomfortable. On `_tape_tag_shift`, C+ blocks three interior titles of which **two are correct** and one merge is wrong. On `_donor_span_slide`, C+ blocks three titles that, by the fixture's own durations, are **probably all correct** (DP residuals 2.0/2.0/0.0 against ~188/88/305 s for the stipulated truth). **Across both regression fixtures, C+'s demonstrated behaviour is mostly declining titles that were right — neither fixture exhibits C+ preventing a wrong adoption.** One stipulates it; the other pins yield cost. So the question this task must answer is narrower and quantitative than "does the class occur": **of the rows C+ declines that the ratio band would otherwise have adopted, how many would have been WRONG and how many RIGHT?** **Report both counts, never only the errors prevented** — a count of errors prevented with no denominator is the same defect as an unlabelled rate. The ground truth is already to hand where the blind arm runs: the hidden taper tags. Three outcomes, all acceptable, **none to be pre-judged**: (a) C+ blocks meaningfully more wrong than right -> it earns its place and the spec's justification stands as written; (b) C+ blocks mostly-correct titles and prevents few or no real errors -> **it is a yield cost paying for insurance against a class that has now failed to be exhibited three times**, which is a legitimate design position, but **the spec must state it plainly and the cost must be quantified**; (c) too few declines in the corpus to say -> **report the N and say so**, which is the honest answer and more useful than a rate computed on four rows. Even under (b) this is **not** license to remove C+: an unreachable-in-89-shows class is not an impossible one, and **a silent adopter is the one surface where being wrong is unrecoverable**. **Prior evidence, from Task 4's fix round — a SECOND instrument pointing the same way.** Constructing a donor-span slide through the real DP proved hard for a mechanistic reason: forcing one through an L1 duration cost requires the two tapes' songs to differ by **minutes**. The credible real-world mechanism — several adjacent near-equal-length songs with one missing from the target — was tried first and **never reaches C+ at all**: the penalties collapse to 2–18 s against `MIN_EXCLUSION_PENALTY = 60`, so layer 3 declines those rows before the guard is ever consulted. The sentence that generalises: **the ambiguity that lets an alignment slide is the same quantity the penalty measures**, so two of the three routes into this class are self-limiting. That argument arrived independently of the sweep's single synthetic observation at agreement 0.80, so Step 9 now has **two converging inputs from different instruments** — a much stronger prior than either alone. **Neither answer is failure, and one reading is forbidden:** if the blind arm finds the class real, the fixture stands and the guard is load-bearing; if it finds the class synthesis-only, then **C+ is insurance rather than a measured necessity and the spec must say so in those words** — cheap insurance against a structurally hard-to-reach failure mode is defensible, but it must not be justified by an implied frequency it does not have. **This is NOT license to remove C+**: an unreachable-in-this-corpus class is not an impossible one, and the corpus is 89 shows. *Structural corollary worth carrying:* if both flanks are right and the donor span count equals the file count, **the interior is forced and cannot slide — so a slide always presents as a count mismatch.** That is why one-sided bracketing (mutation A) structurally cannot kill the donor-span fixture while deleting count-forcing (mutation B) must; the asymmetry is derivable, not incidental. **Required: settle it with the blind arm.** Does a donor-span slide with high anchor agreement arise in the REAL corpus, or only under synthetic masking? Report the count and the population separately, labelled SYNTH and REAL, never pooled. **Both answers are valuable and neither is a failure:** if the class is real, say how often and at what agreement, and Task 4's fixture must be corrected to reproduce it; if it is synthesis-only, then **count-forcing's justification must be restated in honest terms** rather than resting on a case that does not occur in production — the guard may still be worth keeping as cheap insurance, but the spec must say that instead of implying a measured frequency it does not have. A threshold or a guard is only justified over the population its evidence was drawn from.

- [ ] **Step 8 — the scorer must measure the SHIPPED guard, carried from Task 4** (REAL). `siblings._anchor_row` requires `bool(row.proposed)` in addition to the spec's literal denominator ("target tracks carrying a surviving real tag that the alignment paired"), so **a tagged track paired with an UNTITLED donor is neither an agreeing nor a disagreeing anchor**. The narrowing is deliberate and correct — counting it as a disagreement would let one untitled donor track drag a correct alignment below `FLOOR`, a failure mode with no upside — and it is pinned by `test_an_unpaired_tagged_track_is_not_an_anchor`. **This task's scorer MUST adopt the same predicate.** If it computes agreement over a different denominator, the gate certifies a guard that is *not the shipped guard*: the numbers would be internally consistent, reconcile against nothing, and read as a pass — the same class as measuring the wrong tree, one level up, where the instrument is fine but pointed at a slightly different object than the one shipping. **Acceptance: a reconciliation check.** For at least one real pair, the scorer's agreement figure must equal the shipped guard's, obtained by CALLING `siblings.rate_alignment` rather than by reimplementing it.

- [ ] **Step 7 — the target-side-skip cost, carried from Task 3** (REAL). Under L1, skipping and absorbing a target track cost the same, so a target-side skip is structurally rare: `no sibling track` only appears where absorption is illegal (2:2 barred, or `MAX_MERGE`). Elsewhere the DP reports a merge and declines those rows, so **one missing or inserted donor track can cost more than one row** (measured in review: one *inserted* donor track cost 3 of 4 rows, all at penalty 0 s). Task 3 deliberately did NOT add a skip-preferring tie-break, because a tie-break changes which of two **equal-cost** solutions wins — silently changing the population every number in the spec describes, with nothing in the suite able to notice. **Required here: a decision criterion, not an observation.** Answer with numbers: how often does a target-side skip actually arise in the corpus, and when it does, how many rows does the multi-row cost affect across the blind arm? "Structurally rare, and it cost N rows" is a finding a future phase can act on; "structurally rare" alone decays into folklore — the same failure the count-unit rule exists to prevent.
