### Fix candidates
1. **Widen the veto (the Q1 defect).** Within spec section 2, and it only makes the taper own less. Add `\bencor\b`, a glued `^\d{1,3}E[.):]`, a song line `^(\d+\.?\s+)?E\s+[A-Z]`, and `E~` or `-e-` anywhere in an item.
   - Flips 6 library shows plus shakedownband-2013-08-24 from owned to "computed as today".
   - The first three patterns plus `-e-` caught 5 of the 6, plus shakedownband, over all 609 owned library shows and nothing else. The STS9 2004-06-25 case needs `E~` matched mid-item.
   - Measured on the gate's 62 owned rows: no collateral.
   - Risk: `E Street`-style titles get vetoed. That is safe, since it only reduces ownership.
2. **Annotated worded header (R-FORM).** Allow a trailing `(duration|time range|word)` or `...` after a recognised `Set N` or listed `Disc N - Set M` header, treating it like the timestamp section 3 already drops. Flips 3 rows: cowboyjunkies-2012-04-26, joerussosalmostdead-2017-03-11, joerussosalmostdead-2018-02-15.
   - Risk: `Set One (Acoustic)`-style labels become set headers. That is the same set number, so the outcome should not change.
   - Measurement 5 must sample this form, because prose such as "Set I is Bobby and Jerry…" stays excluded only by the requirement that the parenthetical follows the header token directly.
3. **Reader-local item cleaning (R-ITEM).** All of these stay inside the reader, so parse_setlist remains byte-identical. Together they flip 9 rows.
   - Drop items that are only decoration (`=====`), only a parenthetical (`(Electric)`), or only a disc label (`Disc 2:`, `-Disk 2`) in the rest of a header line.
   - Strip `sNtNN:` and `NN:` track prefixes.
   - Strip the enumerated `_NUM_PREFIX` only when `_TRACK_PREFIX` stripped nothing (`44 Blues`). This contradicts the module docstring's "exactly once" claim, which is currently false.
   - Do not split a numbered one-title line on its commas (`Quantico, VA`, `Lordy, Lordy`).
   - Risk: the comma rule is the CLAUDE.md A2 comma defect and should be confined to one-song-per-line enumerated text. Prefix stripping risks `08 Days`-style titles; the `\d{1,3}` guard applies.
4. **Filler vocabulary (`Warm Up`, `Set Break`, 2 rows).** This touches structure.is_filler, which is shared code, so it is outside the reader. I would not do it in this piece.
5. **N-FORM, spec amendment only.** Admitting `Set N Disc M` and similar disc shapes buys 8 more rows, and it is the operator's call.
   - Risk: `Set 1 Disc 2`-style lines are unambiguous.
   - Do not admit `Set 1/2`, `(Start Set N)` or `Disc/SetN` on yield grounds: 0 or 1 flips each.
